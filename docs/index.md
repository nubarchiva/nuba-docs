# Documentación de nubarchiva

nubarchiva es una aplicación web para gestionar archivos. Con ella, un archivo describe sus fondos en varios niveles,
desde el fondo hasta el documento, y los da a conocer a la ciudadanía en un catálogo público (OPAC) y en un portal de
difusión.

## Cómo es esta documentación

Se compone de guías de uso escritas por tareas: cada página explica, paso a paso, cómo hacer una tarea concreta en la
aplicación.

Las páginas describen nubarchiva tal como se distribuye. Tu instalación puede tener personalizaciones, como opciones
ocultas o funciones propias; si algo de lo que ves no coincide con la página, consulta con quien administra tu
instalación.

Una página aparece aquí cuando ya existe la versión de nubarchiva que contiene lo que describe.
